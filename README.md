# Go с нуля - 7 Спринт - Итоговое задание

Начальный код для выполнения итогового задания 7 спринта курса "Разработчик Go с нуля".


### Функция TestCafeCount()

Отправка запросов с различными значениями count и подсчёт количества возвращаемых записей. 

Проверяемые варианты:
```go 
count=0 // не возвращается ни одного кафе;
count=1  // возвращается одно кафе;
count=2  // возвращается два кафе;
count=100  // возвращается минимум из общего количества кафе и 100.
```

### Функция TestCafeSearch()

Проверяет, что полученные в ответе кафе точно содержат переданную в search строку. 

проверяются следующие варианты:

```go
search=фасоль  // не возвращается ни одного кафе;
search=кофе  // возвращается два кафе;
search=вилка  // возвращается одно кафе.
```
